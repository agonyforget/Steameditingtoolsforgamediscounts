# Steam 游戏推广视频一键生产工具

**Steam Video Downloader & Editor** — 面向"游戏推广视频"制作流程的一站式本地工具：粘贴 Steam 链接 → 自动下载素材、抓取价格/折扣/好评率 → 上传真人配音与文案 → 自动生成**完整成片**（片头混剪 + 各游戏段落[字幕+游戏卡片] + 片尾混剪 + 片尾省流总表），并可导出**剪映微调素材包**。

> 🧩 **零配置**：m3u8 解析下载内置（Node 实现）、ffmpeg 内置、本地语音识别（sherpa-onnx + Whisper）可选安装。**只需 Node.js 22+**。

---

## ✨ 功能特性

**素材获取**
- 多链接批量下载 Steam 首个宣传视频（HLS 内置解析，自动合并 mp4）
- **Steam 直抓游戏数据**（免 Excel）：从链接自动提取 价格/折扣%/截止日期/好评率/热门标签
- Excel 表格上传解析（同样支持，双来源可选）

**成片流水线（"自动贴合成片"一键完成）**
- 上传**分段真人配音**（01=片头开场白，02…=各游戏解说），自动按序配对素材
- **文案→字幕**：本地语音识别（whisper）取时间轴 + 上传文案矫正错字 → 输出 `.srt`（软字幕）
- 画面时长按配音自动贴合（+余量），段间淡入淡出转场
- **片头/片尾素材混剪**：自动选取正片未用片段拼接
- **游戏卡片**：每段自动叠加对应游戏信息卡（白底红框，跟随段落显示）
- **片尾省流总表**：游戏数据自动渲染成片尾列表画面
- **可选字幕烧录**进画面（黑边白字；默认不烧，用剪映导入更灵活）

**交付物**
- 完整成片 mp4（H.264 + AAC）
- **剪映微调素材包**：各段画面 + 配套配音 + 对齐字幕 + 组装说明，导入剪映即可微调
- 实时进度（SSE）、跳过已存在、自动去重

## 📦 环境要求

| 依赖 | 说明 |
| --- | --- |
| **Node.js 22+** | 运行环境（需支持 `--use-system-ca`） |
| **ffmpeg** | ✅ 已内置（`bin\ffmpeg.exe`，Windows x64，约 98MB，Release 附件提供） |

### 📥 获取内置组件（Release 附件）

1. `ffmpeg-win-x64.zip` → 解压出 `ffmpeg.exe` 放入项目 `bin\`
2. `sherpa-asr-win-x64.zip` → 解压出 `sherpa-onnx\` 放入项目根目录

## 📖 推荐工作流（完整成片）

```
① 下载素材    ：粘贴 Steam 链接 → 开始下载（素材落 material/）
② 抓取数据    ：「📊 游戏数据」→ Steam 直抓 或 Excel 上传解析
③ 上传配音    ：01_开场白.mp3、02_游戏A.mp3、03_游戏B.mp3…
④（可选）文案→字幕：选配音 + 贴文案 → 生成 srt（落配音目录）
⑤ 自动贴合成片：载入素材（数量=解说数）→ 生成
   → 完整成片：片头混剪(01开场白) + A段(字幕+卡片) + B段 + 片尾混剪 + 省流总表
   → 同目录生成「xxx_剪映素材包」供剪映微调
```

**要点**：
- 配音比素材**多 1 段**即启用片头（第 1 个自动当开场白）；数量相等则无片头纯正片
- 每段画面时长 = 对应配音时长 + 余量（默认 2s，可调）；段间转场默认 0.5s（0=硬切）
- 勾选「烧录字幕进画面」出带字幕成品；不勾则用素材包的 .srt 在剪映里导入编辑

## 🧭 使用教程（按流水线顺序分步）

页面顶部有功能状态条（引擎就绪提示），往下按"下载 → 配音 → 字幕 → 数据 → 成片"编排了多张功能卡。下面按一条完整流水线逐步说明。

### ① 下载素材（第一张卡）

1. 输入框粘贴 Steam 商店链接，**每行一个**，例如：
   ```
   https://store.steampowered.com/app/590380/Into_the_Breach/
   https://store.steampowered.com/app/105600/Terraria/
   ```
   （也支持纯数字 appid；重复链接自动去重；可勾选"跳过已存在"避免重复下载）
2. 点「▶ 开始下载」，等待卡片变绿。每个游戏会经历：获取信息 → 下载分片 → 合并 mp4
3. 素材保存到素材目录（默认 `E:\worddeepseek\videocut\material`，可在输入框改），命名 `日期_游戏名_视频素材.mp4`
4. 点「📂 打开素材文件夹」可直接查看

### ② 抓取游戏数据（第二张卡：Steam 直抓 / Excel 二选一）

**方式 A：Steam 链接直抓（免表格）**
1. 点「🔗 Steam 链接直抓」
2. 粘贴 Steam 链接（每行一个，**顺序 = 后面素材/配音的顺序**）
3. 点「抓取」→ 自动得到：原价 / 现价 / 折扣% / 折扣截止 / 好评率 / **Key 价** / 热门标签
   > Key 价来自 SteamPY 实时市场，**会波动**，录视频建议当天抓取

**方式 B：Excel 表格**
1. 点「📊 Excel 上传」→ 选 .xlsx → 选工作表 → 「解析」
2. 表头建议列：`游戏名 | 原价 | 现价 | 好评率 | 折扣力度 | 截止日期 | 标签1 | 标签2`（可加 `key价格` 列自动显示）
3. 行顺序 = 段落顺序（第 1 行 ↔ 第 1 段解说）

### ③ 上传配音（第三张卡）

1. 点「📁 选择文件」或把音频拖进卡片（支持 mp3/wav/m4a/aac…）
2. **命名规则**（决定顺序与角色）：
   ```
   01_开场白.mp3    ← 第 1 个必须是片头开场白
   02_游戏A.mp3     ← 第 2 个开始才是各游戏解说
   03_游戏B.mp3
   ```
3. 上传后自动按 `01/02/03…` 排序展示；顺序 = 素材顺序 = 数据行顺序

### ④ 文案 → 字幕（第四张卡，可选但推荐）

> 需先装语音识别引擎（Release 附件 `sherpa-asr-win-x64.zip` 解压到项目根目录）

1. 选择一段配音
2. 粘贴对应文案（或 📄 载入 .txt；按换行/句号自动分句）
3. 点「生成字幕」→ 本地识别配音拿时间轴 + 你的文案矫正错字 → 输出 `.srt`
4. 字幕默认存到配音目录（与配音同名），可用上方输入框改目录
5. 页面可预览/复制 srt；**每段配音都生成后，成片就能自动带字幕**

### ⑤ 自动贴合成片（第五张卡：一键出完整片）

1. 「📁 载入素材」：载入**游戏解说对应的素材**（数量 = 解说数，如 2 段解说就 2 个素材）
2. 「🎙️ 载入配音」：载入全部配音（含 01 开场白）
   - 页面会提示配对状态：配音比素材多 1 = 带片头；相等 = 无片头
3. 调参数（可留默认）：
   - 画面余量：每段画面比配音多出的秒数（默认 2s）
   - 段间转场：淡入淡出秒数（默认 0.5；0 = 硬切）
   - 烧录字幕进画面：☑ 出带字幕成品；不勾则字幕走素材包的 .srt
4. 点「▶ 生成贴合成片」，等待完成（转场 + 总表渲染较耗时）
5. 产物：
   - `成品名.mp4` → 完整成片（片头混剪 + 各段[字幕+游戏卡] + 片尾混剪 + 省流总表）
   - `成品名_剪映素材包\` → 分段的画面/配音/字幕 + 组装说明

### ⑥ 用剪映微调（素材包）

1. 打开 `xxx_剪映素材包` 文件夹，按 `组装说明.txt` 把 mp4 按序号拖入剪映视频轨
2. 配音 `.wav/.mp3` 拖到音频轨（与画面配套）
3. `.srt` 字幕：剪映「文本 → 导入字幕/本地字幕」，自动按时间排好
4. 改错字、调样式、换顺序后导出即可

### ⑦ 补充功能

- **🃏 游戏卡片叠加**：若要对"已完成成片"单独加卡片：填成片路径 → 「从已解析 Excel 载入卡片」→「按段落自动排布时间」→ 生成
- **🎬 剪辑拼接成片**：手动模式——给素材填起止时间（如 `1:00` / `90`）逐段指定，供不按配音的手动剪辑

### ⑧ 一个完整示例（3 款游戏一期）

```
配音文件：01_开场白.mp3、02_Into the Breach.mp3、03_Terraria.mp3
1. ①下载：粘贴 2 个游戏链接 → 下载完成
2. ②数据：Steam 直抓这 2 个链接
3. ③配音：上传上面 3 个音频
4. ④字幕：为 02/03 配音各生成一次字幕
5. ⑤成片：载入素材选 2 个（Into the Breach → Terraria 顺序对应 02/03）
   → 生成 → 得到：片头(01开场白+混剪) + 段1(字幕+卡片) + 段2 + 片尾混剪 + 省流总表
   → 旁出「xxx_剪映素材包」可微调
```

## ❓ 常见问题

- **证书错误**：脚本自动 `--use-system-ca` 重启信任系统证书；仍失败加 `--insecure`
- **需要代理**：设 `HTTPS_PROXY` 或 `--proxy=http://127.0.0.1:7890`
- **找不到语音引擎**：从 Release 下载 `sherpa-asr-win-x64.zip` 解压到项目根目录
- **"素材未用片段不足"**：片头/片尾混剪需要素材留有未剪辑部分，素材太少/太短会提示
- **个别游戏只提供 DASH(.mpd)**：暂不支持，明确提示（绝大多数提供 HLS）
- **端口占用**：改 `PORT`（如 `set PORT=8899`）
