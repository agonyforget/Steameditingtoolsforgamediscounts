# Steam 视频批量下载与剪辑工具

**Steam Video Downloader & Editor** — 一个开箱即用的本地网页工具：粘贴多个 Steam 商店链接，自动下载每个游戏的第一个宣传视频；内置剪辑拼接功能，可按时段剪辑并拼接成片。

> 🧩 **零配置**：m3u8 解析与分片下载完全内置（Node 实现），合并引擎内置 ffmpeg，无需安装任何外部 m3u8 解析器。**只需 Node.js 22+**。

---

## ✨ 功能特性

- **多链接批量下载**：文本框一次粘贴多个 Steam 商店链接（或纯数字 appid），自动识别、去重，逐个下载
- **取第一个宣传视频**：调用 Steam appdetails 接口，自动获取每个游戏的宣传视频
- **HLS 能力完全内置**：Steam 现在只提供 `.m3u8` / `.mpd` 流地址。解析 + 分片下载由 Node 内置实现（信任系统证书，可正常访问 Steam 视频 CDN），合并成 mp4 使用内置 ffmpeg，**无需安装/配置任何外部 m3u8 解析器**
- **剪辑拼接成片**：为素材填起止时间（如 `1:00-1:30`），一键流拷贝无损剪辑拼接，自动处理不同帧率素材拼接的时间戳兼容问题
- **统一命名**：素材 `当天日期_游戏名_视频素材.mp4`，成品 `日期_游戏名1_游戏名2…`
- **实时进度**：网页内 SSE 实时刷新每个任务的状态、进度条、速度与日志
- **跳过已存在**：默认跳过已下载过的同名文件；单个失败/取消不阻塞其他游戏
- **网络兼容**：自动以 `--use-system-ca` 信任系统证书库；支持 HTTPS_PROXY 等代理环境变量

## 📦 环境要求

| 依赖 | 说明 |
| --- | --- |
| **Node.js 22+** | 运行环境（需支持 `--use-system-ca`） |
| **ffmpeg** | ✅ **已内置**（`bin\ffmpeg.exe`，Windows x64，约 98MB）；找不到时自动回退系统安装或 PATH |

> 非 Windows 平台：`bin\` 下的 ffmpeg 仅适用于 Windows x64。macOS/Linux 用户请自行安装 ffmpeg，或设置 `FFMPEG_PATH` 环境变量指向本机 ffmpeg。

### 📥 获取内置 ffmpeg（Windows）

本项目将 ffmpeg 二进制（约 98MB）通过 **Release 附件**提供（不入 Git 仓库，避免仓库过大）：

1. 前往本项目的 **Releases** 页面，下载 `ffmpeg-win-x64.zip`
2. 解压得到 `ffmpeg.exe`，放入项目目录的 `bin\` 文件夹（没有就新建一个）
3. 完成，双击 `start-steam-video.cmd` 即开箱即用

> 备选：自行安装 ffmpeg（如 gyan.dev 或 winget install ffmpeg）后设置 `FFMPEG_PATH`，无需 `bin\`。

## 🚀 快速开始

1. **下载/解压**本项目（或 `git clone`）
2. **双击 `start-steam-video.cmd`**（Windows），保持窗口开启
3. 浏览器打开 **http://localhost:8898**
4. 粘贴 Steam 链接，点击「▶ 开始下载」

> 命令行方式：`node --use-system-ca steam-video-downloader.mjs`

## 📖 使用说明

### 一、下载游戏宣传视频（素材）

1. 在输入框中粘贴 Steam 商店链接，**每行一个**：

   ```
   https://store.steampowered.com/app/1623730/Palworld/
   https://store.steampowered.com/app/105600/Terraria/
   https://store.steampowered.com/app/648800/Raft/
   ```

   也支持直接填纯数字 appid（如 `1623730`），重复链接自动去重。

2. 点击「▶ 开始下载」。每个游戏会经历：`获取游戏信息 → 下载分片（视频+音轨）→ 合并成 mp4`，网页实时显示进度条与日志。
3. 完成后素材保存到 **`E:\worddeepseek\videocut\material`**（可在"视频保存目录"输入框修改），文件名为 `2026-09-01_Palworld_视频素材.mp4` 格式。
4. 点「📂 打开素材文件夹」可快速查看。

### 二、剪辑拼接成片

1. 在页面下方「🎬 剪辑拼接成片」区点击「载入素材」，自动列出素材目录的视频（也可「＋ 手动添加素材」）。
2. 为每个素材填写：
   - **名称**：默认自动解析游戏名，可修改（用于成品命名）
   - **开始 / 结束**：时间格式支持 `1:00`、`90`、`1:30.5`、`01:02:03`；**留空 = 从头/到结尾**
3. 用 **↑ / ↓** 调整拼接顺序，**×** 移除不需要的素材。
4. 设置**成品目录**（默认 `E:\worddeepseek\videocut\product`）与**成品名**（留空自动生成 `日期_名称1_名称2…`）。
5. 点击「▶ 拼接成片」，完成后在结果区显示输出路径，成品列表自动刷新。

> 拼接为**流拷贝无损模式**：剪辑按关键帧对齐（秒级、无画质损失），程序会自动统一各片段时间基，解决不同帧率素材（如 60fps 与 29.97fps）拼接后的时间戳错乱问题。

## 🏗️ 工作原理

```
下载流程（完全内置，无需外部工具）
┌────────────────────────────────────────────────────────────────┐
│ 1. 解析链接 → 提取 appid（支持商店链接/纯数字）                  │
│ 2. 调用 Steam appdetails 接口 → 取第一个视频的 HLS(.m3u8) 地址    │
│ 3. Node 内置解析播放清单（自动选最高画质/480p、处理音轨分组）      │
│ 4. Node 并发下载视频+音轨分片（信任系统证书，可访问 Steam CDN）    │
│ 5. 改写成本地播放清单 → 内置 ffmpeg 合并成 mp4（视频+音频）        │
└────────────────────────────────────────────────────────────────┘

剪辑拼接流程（流拷贝无损）
┌────────────────────────────────────────────────────────────────┐
│ 1. ffmpeg 按时段裁剪（-ss/-t 流拷贝，关键帧对齐，秒级）           │
│ 2. 统一视频时间基（-video_track_timescale，仅重写时间戳无损失）    │
│ 3. concat 列表流拷贝拼接 → 输出成品                              │
└────────────────────────────────────────────────────────────────┘
```

**为什么不用 N_m3u8DL-CLI / yt-dlp 等外部工具？**

- Steam 视频 CDN 对 .NET/部分工具链的 TLS 栈不兼容（直连会报"接收时发生错误"），而 Node 信任系统证书后可正常访问；
- 因此下载阶段使用 Node 内置实现（可靠、可控），合并阶段使用内置 ffmpeg，**开箱即用、零配置**。

## ❓ 常见问题（FAQ）

**Q：提示证书错误（unable to verify the first certificate）？**
脚本已自动以 `--use-system-ca` 重启并信任系统证书库；仍失败可加 `--insecure` 参数（不安全）。

**Q：访问 Steam 需要代理？**
设置 `HTTPS_PROXY` 环境变量后重启，或启动时加参数 `--proxy=http://127.0.0.1:7890`（支持 http/https/socks5）。

**Q：提示找不到 ffmpeg？**
正常情况下工具目录 `bin\` 已内置 ffmpeg；若被误删，可把任意 ffmpeg.exe 放回 `bin\`，或设置 `FFMPEG_PATH`。

**Q：个别游戏显示「无视频」？**
该游戏商店页没有宣传视频，不影响其他游戏下载。

**Q：个别游戏只提供 DASH 流（.mpd）？**
当前版本暂不支持 DASH，会明确标记失败（Steam 绝大多数视频均提供 HLS）。

**Q：端口 8898 被占用？**
设置 `PORT` 换端口，如 `set PORT=8899 && node --use-system-ca steam-video-downloader.mjs`。
